Назначение
Класс BurgerMenu управляет мобильным бургер-меню: открытие/закрытие по клику, закрытие свайпом, по клику вне меню или по ссылке внутри. Автоматически включает/выключает обработчики в зависимости от ширины экрана. Опционально интегрируется с классом фиксированной шапки.


Требуемые CSS-классы в HTML
Класс BurgerMenu находит элементы через document.querySelector по именам классов из объекта config. Вот минимальный набор элементов, которые обязаны присутствовать в DOM:

CSS-класс         (ключ config)	Элемент	Назначение

BURGER	          Кнопка-бургер	Кнопка открытия/закрытия меню
HEADER_MENU	      Контейнер меню	Блок, который показывается/скрывается
PAGE_BODY	<body>	Блокировка скролла при открытом меню
MAIN	<main>	    Блокировка кликов по основному контенту (опционально)
MENU_LINK	        Ссылки в меню	Клик по ссылке закрывает меню


Дополнительные классы-модификаторы, которые добавляются/удаляются кодом:

Ключ config	Назначение

BURGER_OPEN	         добавляется кнопке при открытом меню
HEADER_MENU_OPEN	   добавляется контейнеру меню при открытии
PAGE_BODY_NO_SCROLL	 добавляется body для блокировки прокрутки
